# playground

Chore Wars liegt in [`chore-wars/`](chore-wars/). Die App ist ein offline-fähiger Haushalts-Tracker für zwei Spieler auf demselben Gerät. In der App lassen sich Aufgaben nach Kategorie filtern und durchsuchen, anlegen, ändern, löschen und innerhalb der Kategorie sortieren, die beiden Namen ändern, die letzte Buchung rückgängig machen und der Stand als JSON sichern. Punkte zurücksetzen leert nur den aktuellen Stand und den Verlauf, nicht die Aufgaben, Namen oder Statistik. Öffnen mit `chore-wars/index.html`. Die Spiellogik prüft `node chore-wars/state.test.js`.

tf_modeling liegt in [`tf_modeling/`](tf_modeling/). Die App rechnet lineare Schaltungen offline auf dem Gerät. Öffnen mit `tf_modeling/index.html`.
